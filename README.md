\# AI Grid Resilience Copilot



An Explainable Graph Reinforcement Learning Copilot for Predictive Fault, Congestion, and Renewable-Aware Resilience in Smart Distribution Grids.



\## Features



\* Temporal Graph Neural Networks

\* Renewable-Aware Stress Modeling

\* Explainable Graph Attention

\* Multi-Risk Prediction

\* RL-Assisted Operator Recommendations

\* Cascading Risk Simulation

\* Streamlit Dashboard



\## Final Validated Results



\* 92%+ Macro F1

\* 98%+ Macro AUC

\* 96%+ Macro AUPRC



\## Architecture



\* GCN

\* GAT

\* STGCN

\* ResiliGraph-STGAT



\## Dashboard



Operator-facing resilience intelligence dashboard with:



\* AI attention heatmaps

\* risk prediction

\* explainability

\* RL mitigation recommendations

\* renewable stress benchmarking



\## Run



```bash

pip install -r requirements.txt

streamlit run dashboard/app.py

```
